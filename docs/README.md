# docs/

Project documents and evidence for PromptVault.

| Location | Contents |
|---|---|
| `logo/` | team logo (PDF and image files) |
| `wireframes/` | wireframes for the top-level pages |
| `screenshots/` | evidence screenshots: terminal output, Postman results, browser screens |
| `EDD_v1.pdf` | External Design Document v1: team name, logo, table of contents, wireframes and initial screenshots |
| `api-contract.md` | request and response formats for every endpoint |
| `backlog-snapshot.pdf` | Product Backlog snapshot from Jira |

## Conventions

- Start each file name with its Jira key, for example `SCRUM-12_health-endpoint.png`.
- Hide passwords, tokens and connection strings in screenshots before committing them.
- This repository is public. The signed team contract, student IDs and team photos are submitted on Luminate and are not committed here.
